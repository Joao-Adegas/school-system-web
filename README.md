# Academic Management System Web

Web frontend of the Academic Management System, used to manage professors, courses and room reservations. It consumes the [school-system-api](https://github.com/Joao-Adegas/school-system-api).

## Features

- Login with JWT authentication
- **Managers:** manage professors, courses and room reservations
- **Professors:** view their linked courses and reservations
